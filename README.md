Exactly one word — the word Grandma would text about AI — written for the [make.fun bounty](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

Why "Doohickey": a grandma calls any gadget she cannot name a doohickey. It is warm, a little baffled, tied to machines, and funny with no caption needed.

## Run it

```sh
python3 main.py
```
